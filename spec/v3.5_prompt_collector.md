## 1. 产品一句话

用户在 **Prompt 工作台** 用一句话生成可粘贴的自然语言分镜 Prompt（同一角色、行×列拍数对齐），复制到自己的生图工具出拼图，再回到 **动图工坊** 切片导出。设置页管主题与写 Prompt 的 API。

## 3. 已对齐的架构决策

| 决策 | 裁定 | 理由 |
|------|------|------|
| 主存 | **SQLite**（标准库 `sqlite3`） | 事务抗损坏；3.5.1 可加 Agent 历史表；不上 ORM |
| 备份格式 | **JSON + Markdown** | 满足「换机备份」需求，与主库分离 |
| 密钥 | **独立设置存储**，禁止写入 `library.sqlite` | 收藏是作品，Key 是机密 |
| Agent 协议 | **OpenAI 兼容 Chat Completions**（`urllib`，无新依赖） | 一套客户端覆盖 OpenAI / DeepSeek / 本地 Ollama / **OpenRouter** |
| OpenRouter | **写 Prompt 的 LLM 通道（推荐）** | 一个 Key 路由文本模型；**不是**生图后端 |
| 生图目标 | **自然语言 Prompt，界面不出现具体生图产品名** | 内部按 NL 分镜板写；用户拿到哪家工具出图由自己决定 |
| 生图 API 调用 | **3.5.1 默认可复制 NL Prompt；工坊内直接出图另批** | 本地已有素材图仍禁止上传；若直连生图 API 也只发文本 Prompt |
| 依赖 | 不新增 `openai` / `requests` / `httpx` / ORM | 运行时仍 Pillow + PyQt6 + Fluent |
| UI | 见第 4.5 / 5.1 / 5.4，对齐 `docs/prototype.html` | 少文案、有字段名；主题横排 |

隐私总则：

- 图像处理 100% 本地，与现在完全一致。
- Agent 请求体 **只含** 用户填写的灵感、角色锚点、网格、风格、系统配方；**不含** 任何像素、文件路径、图。
- 未配置 Key 或用户不点生成时，软件保持离线。

## 4. v3.5.0 功能规格 — 本地 Prompt 收集器

### 4.1 用户故事

1. 打开左侧「Prompt」，在左栏收藏里选中、搜索、导入、导出。
2. 右栏选网格（快捷或行×列），编辑 Prompt，复制或保存。
3. 不配 API Key 也能用手写/粘贴 Prompt 与收藏（完善为 3.5.1）。

### 4.2 数据字段 `PromptRecord`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | TEXT PK | uuid4 |
| `title` | TEXT | 列表名 |
| `prompt` | TEXT | 正向词 |
| `negative` | TEXT | 负向词，可空 |
| `image_model` | TEXT | 可选内部标记，**不在 UI 展示产品名**；可空 |
| `aspect` | TEXT | 自然语言画幅，如 `1:1`、`3:4`、`16:9`（写入句子，不用 `--ar`） |
| `grid` | TEXT | 存 `"{rows}x{cols}"`，如 `3x3`、`3x4` |
| `tags` | 多对多 | 风格标签 |
| `notes` | TEXT | 备注 |
| `created_at` / `updated_at` | TEXT ISO-8601 UTC | |
| `schema_version` | INTEGER | 当前 `1` |

建议预置标签：`二次元`、`像素风`、`黏土风`、`3D写实`、`表情包`、`连环画`（用户可增删）。

### 4.3 存储路径

- 主库：`{base_dir}/output/prompts/library.sqlite`
- 导出默认目录：同 `output/prompts/`
- 无写权限：降级 `%USERPROFILE%/Pictures/GifCreater/output/prompts/`（复用 `paths.py`）
- Git 忽略：已覆盖 `output/`；禁止把 sqlite / 密钥提交进仓库

### 4.4 无头模块

```
src/gifcreater/core/prompt_schema.py   # dataclass + 校验
src/gifcreater/core/prompt_store.py    # sqlite CRUD / 标签 / 导入导出
```

`PromptStore`：`list` / `get` / `create` / `update` / `delete` / `duplicate` / `export_json` / `import_json` / `export_markdown`。

坏库：无法打开时备份为 `.bak` 并报明确错误，不静默空库覆盖用户数据（除非用户确认重建）。

### 4.5 / 5.4 UI 规格（已拍板）

权威交互稿：`docs/prototype.html`。控件必须有短名称，禁止步骤条、产品名、教程句。

**左侧导航（三项）**

| 项 | 内容 |
|----|------|
| 动图工坊 | 现有切图；侧栏 **不** 出现 Prompt 卡 |
| Prompt | 独立整页工作台 |
| 设置 | 外观 + API |

**Prompt 页**

```text
左栏「收藏」     右栏
  搜索             网格  2×2  3×3  1×6  4×4   行 [ ]  列 [ ]
  列表（标题+格）   提示  [                  ]  [完善]
  [导出] [导入]     Prompt
                   [多行文本]
                   [复制] [保存]
```

- 完善：3.5.1 才发请求；无 Key 时 InfoBar 提示去设置，不发网。
- 无第二输入「继续改」。再改：改提示或改正文后再次完善。
- 禁止把 Prompt 写入配文框。
- 列表次要信息显示网格（如 `3×3`），不显示生图产品名。

**设置页**

```text
外观
  主题   ( ) 深色  ( ) 浅色     ← 同一行，禁止竖排

API

  Base URL
```

## 5. v3.5.1 功能规格 — 设置页 + OpenRouter + 网格 Agent

### 5.1 设置页（外观 + API，均持久化）

与工坊、Prompt 工作台并列。**禁止**把网格、画幅、Prompt 正文放进设置。

**必须落盘，下次启动恢复。** 现有 `ThemeManager` 只在内存里，关掉即回深色，这是缺口。

| 项 | 存哪 | 说明 |
|----|------|------|
| 主题 `dark` / `light` | 非机密 JSON | 设置页选择；工坊顶栏切换主题写同一份 |
| Provider / Base URL / 模型 ID | 同上 JSON | |
| API Key | 独立密文，不进 JSON、不进 sqlite | Windows DPAPI |

路径：`{writable}/gifcreater-settings.json`（可写目录优先安装目录，否则 `Pictures/GifCreater/`，复用 `paths.py` 降级）。密文旁路 `gifcreater-secrets.bin`。

启动：读 JSON → `ThemeManager.set_theme`；读密文填入内存，UI 只显示「已保存」。

**LLM Provider 卡片**

| 字段 | 说明 |
|------|------|
| Provider 预设 | `OpenRouter`（默认推荐）/ `OpenAI` / `DeepSeek` / `Ollama (本地)` / `自定义` |
| Base URL | 预设自动填；自定义可改 |
| 模型 ID | 如 OpenRouter：`openai/gpt-4o-mini`、`anthropic/claude-sonnet-4`、`google/gemini-2.5-flash`（占位以当时文档为准，UI 可手填） |
| API Key | 密码框，保存后只显示「已保存」；支持清除 |
| 测试连接 | 发一条极短请求，InfoBar 成功/失败（不把 Key 打进日志） |

**OpenRouter 预设（一等公民）**

- Base URL 固定默认：`https://openrouter.ai/api/v1`
- 请求：`POST {base}/chat/completions`
- Header：`Authorization: Bearer <key>`；另加 OpenRouter 建议的 `HTTP-Referer`、`X-Title`（应用名 `GifCreater`，Referer 用本地应用标识，不含用户数据）
- 模型：用户填写 OpenRouter 的 `provider/model` 字符串
- 一个 Key 即可换模型，不必为 Claude/GPT 各开一套

其他预设仅改默认 Base URL（均可再手改）：

| 预设 | 默认 Base URL |
|------|----------------|
| OpenRouter | `https://openrouter.ai/api/v1` |
| OpenAI | `https://api.openai.com/v1` |
| DeepSeek | `https://api.deepseek.com/v1` |
| Ollama | `http://127.0.0.1:11434/v1` |
| 自定义 | 空，必填 |

**密钥存储**

- 与 sqlite 收藏库分离，例如 `output/prompts/settings.json` 只存非机密（provider、base_url、model、defaults）
- API Key：Windows 上优先 DPAPI（`ctypes` / 标准库）加密后写入本地；无法 DPAPI 时拒绝明文落盘并提示（审核时可改为「开发阶段允许本机明文，发布再加密」——见第 8 节开放问题）
- 日志、异常、InfoBar **禁止**打印 Key

### 5.2 Agent：只做 Prompt 工程师

无头：`src/gifcreater/core/agent_engine.py`

- `OpenAICompatibleClient.complete(messages, model, timeout)` → 文本
- `StoryboardPipeline.run(brief: GenerationBrief) -> GenerationResult`
- UI 经 `QThread` Worker 调用，界面不冻；可取消

`GenerationBrief`：

- `inspiration`：提示框文本
- `current_prompt`：现有 Prompt 正文（可空）
- `rows` / `cols`：1–20，拍数 = 行×列

`GenerationResult`：

- `title`、`character_sheet`、`full_prompt`（**一整段自然语言**，可直接粘贴到对应生图模型）、`beats[]`（每格一句动作，同样是自然语言）、`negative`（若该模型有用则附在正文里用句子表达「不要…」，不用 SD 式 tag 堆砌）

失败：超时、401、余额、JSON 解析失败 → 用户可读中文 InfoBar，不崩进程。

### 5.3 内置分镜配方（核心服务）

系统提示词（版本化，可单测快照）强制：

1. **同一角色**：每格外貌/服装/发型/体型锁死，禁止换人。
2. **格数必须等于网格**：`3×3` → 恰好 9 拍；`4×4` → 恰好 16 拍；禁止多写少写。
3. **时序连续**：起势 → 加速 → 高潮 → 收势，相邻格动作可接上。
4. **机位规则**：默认同一机位中近景，除非用户写明运镜。
5. **只输出自然语言**：禁止 `--ar` / `--v` / `--grid` 等参数；写明单张分镜拼图、行列、从左到右从上到下、角色锁定。
6. `full_prompt` 可直接粘贴；界面不出现具体生图产品名。

网格：快捷 `2×2` / `3×3` / `1×6` / `4×4`，另加 **自定义行×列**（1–20，与工坊切片 SpinBox 一致）。Agent 按 `rows × cols` 强制拍数 = 行×列。

### 5.5 Agent 历史（可选轻量）

3.5.1 可在同一 sqlite 增加 `agent_runs`（brief 摘要、结果、时间、模型 ID）。**不存 API Key**。若首版要砍范围，可只入库 `PromptRecord`、不留历史表。

## 6. 明确不做（本里程碑）

- 对接 Midjourney / Flux / SDXL 生图或它们的参数语法
- 把本地拼图、切片、缩略图发给 LLM 或生图 API
- 默认范围内：工坊代为调用 Nano Banana / GPT Image **出图 HTTP**（除非第 8 节拍板「3.5.1 直连生图」）
- 自动把 Prompt 灌进画面配文
- `openai` SDK、LangChain、新 GUI 框架
- macOS 钥匙串（3.5.1 以 Windows 为主，与现产品一致）
- 多账号 / 团队云同步

---

## 7. 测试与质量门禁

- `tests/unit/test_prompt_schema.py` / `test_prompt_store.py`：CRUD、标签、导入合并、坏库
- `tests/unit/test_agent_engine.py`：配方格数、禁止 MJ 参数、NL 全文可粘贴、Mock HTTP（禁止真打 OpenRouter / 生图 API）
- `tests/unit/test_settings_secrets.py`：Key 不出现在 sqlite；序列化不含明文（若启用加密）
- 覆盖率 ≥ 90%；图像仍用内存微型图；sqlite 用 `tmp_path`
